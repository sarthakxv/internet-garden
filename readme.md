# Sarthak's Internet Garden

A personal documentation site built with [Nextra 4.x](https://nextra.site) and [Next.js 15](https://nextjs.org) using the App Router.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Technologies Used

- [Next.js 15](https://nextjs.org) - React framework
- [Nextra 4.x](https://nextra.site) - Documentation framework
- [React 19](https://react.dev) - UI library
- TypeScript - Type safety
